# Talks N Walks — Locked Visual Direction

This file is the visual source of truth for daily post artwork.

## Core style

**Pastel + peaceful + premium + simple + soft.**

The post should feel calm, relatable and elegant rather than cinematic or dramatic.

## Palette

Pastel colours should dominate. Preferred families:

- lavender
- blush pink
- peach
- warm cream
- sage
- powder blue
- muted soft teal

Avoid harsh black backgrounds, neon colours, heavy saturation and fiery orange/gold skies.

## Scene direction

Prefer gentle everyday scenes with visual depth, for example:

- quiet window / reading corner
- calm desk, notebook, coffee or books
- peaceful balcony or garden
- soft wellness / fitness room
- study setting
- bicycle, path or simple travel scene
- beach walkway or calm nature
- friendship / family moments

Scenes should be attractive but not overloaded. Leave a naturally quiet area for quote typography.

## Drama level

Keep drama low.

Avoid:

- exaggerated cinematic lighting
- overly emotional or heroic posing
- dark heavy shadows
- intense sunset skies
- cluttered compositions
- flat-vector mountain/poster fallbacks
- clip-art look
- thick black line-art as the main visual style

## Audience

Publishing streams remain Women/general, Men, and Children/teens, but the visual should not become unnecessarily gendered.

If a quote is universal, prefer a unisex scene such as nature, travel, workspace, books, coffee, a road, fitness objects or another neutral visual metaphor.

## Branding

The background artwork must not generate or redraw branding.

Code adds branding afterward:

1. quote / attribution
2. lowercase `@talksnwalks101`
3. the fixed small monochrome Talks N Walks logo underneath the handle

The logo is a locked asset and should not be regenerated as part of a scene.

## Production principle

Do not substitute a visibly poor generic fallback simply to make a build pass. Keep the previous stable renderer available as an explicit fallback, but the preferred no-API production renderer is the curated pastel scene library.
