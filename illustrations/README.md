# Talk N Walks illustration assets

Illustrations are now auto-detected from each stream folder. You no longer need a hard-coded 12-file list.

## Naming convention

Use:

`audience_topic_scene_XX.png`

Examples:
- `women_fitness_deadlift_01.png`
- `women_friendship_vacation_01.png`
- `women_relationships_beach_walk_01.png`
- `men_fitness_plank_01.png`
- `men_friendship_car_01.png`
- `men_reading_coffee_01.png`
- `kids_friendship_cycling_01.png`
- `kids_family_mother_hug_01.png`
- `teens_study_books_01.png`
- `all_relationships_proposal_01.png`

Use lowercase letters, underscores, a short scene description, and a two-digit variant number.

## Folders

- Women/general: `illustrations/`
- Men: `illustrations/men/`
- Children/teens: `illustrations/children/`

The builder scans every PNG in the relevant folder, removes exact duplicate image files by content hash, and spreads filenames across topic/category keys. Each unique image is used once before the rotation starts again.

Legacy filenames such as `reading_01.png` remain compatible while assets are being renamed.

## Master visual standard

Every illustration used by Talk N Walks must match the established light editorial line-art look.

Required:
- very fine black or charcoal line work
- thin, delicate strokes rather than bold outlines
- generous transparent/negative space
- modern, reasonably realistic human proportions
- clean monochrome illustration only
- minimal detail and restrained texture
- transparent background where possible
- small-to-medium visual weight so the quote remains dominant
- modest, non-sexualized clothing and posing for women, girls, and teens

Reject assets with:
- thick or heavy black outlines
- large solid-black clothing/hair/body areas that dominate the frame
- dense cross-hatching, pencil shading, comic-book inking, or charcoal texture
- dark backgrounds, frames, scenery, or decorative clutter
- text, quotes, usernames, captions, or logos embedded in the artwork
- cleavage-focused clothing or sexualized posing
- exaggerated cartoon anatomy unless specifically approved for a children asset

When choosing between two otherwise suitable illustrations, prefer the lighter and airier one. The illustration should support the quote, never visually overpower it.
