# Children, pre-teen, and teen illustrations

Put approved TalksNWalks101 PNG illustrations for kids, pre-teens, and teens in this folder.

Requirements:
- one illustration per PNG
- clean black-and-white drawing style
- transparent background preferred
- no quote text, username, border, or full-frame background
- inclusive, age-appropriate scenes with no gender bias
- filenames should be descriptive and stable

`build_children.py` automatically uses PNG files from this folder.
